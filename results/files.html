The population model

The aggregator first read each case on its own. It drafted the coding scheme at B1, froze the definitions for the readers at B2, settled their disputed placements at B4 and revised the scheme at C1. Its A1 note on r/PlaceNL and the C5 coding table show how that community entered the model.

Choose a stage to see its files and what each contains.

Reading

A1 Community notes

Read each community on its own terms

Coding

B1 Third-order scheme

Build a shared set of categories

B2 Pilot

Test whether others can use the scheme

B3 Independent readers

Read the material independently, twice

B4 Adjudication and freeze

Resolve placements by returning to evidence

Model

C1 Structuring

Turn the categories into a structure

C2 The loop

Build an explanation and try to break it

C3 Literature

Put the model into conversation with theory

C4 R/place

Compare the inside view with the wider event

C5 Account

Write the whole account and expose its weak points

Adaptation: the return

D1 Return build

Prepare to give the model back to each community

D2 Labelers and verdicts

Collect the communities' answers

D3 Adjudication

Decide what the return changes

Forming

D4 The tree

Find shared forms in the changes communities need

D5 Branch accounts

Explain what each proposed form does

D6 The retelling

Retell the whole model with its forms inside it

Formalizing

E1 Audit

Audit what the run supports

E2 Feedback

Review the handling and design the next instrument
