Run the study

Open three handler chats in order: the collection handler, then the coding handler and the aggregator handler. Give each its brief before asking it to obtain the working folders. Each guide has the prompt to paste, the checks and when to move on; below is what each handler does.

1. Collection handler

It builds each community's record from the public pixel record, the atlas and the Reddit archives, following the collection recipes; the census decisions come with the data. The collection guide · See the data recipes and the agent instructions.

2. Coding handler

It codes each community with its community coder, and fleet coders above 500 items, and keeps each coder's conversation and files so the coder can be resumed. A local model (R6), the return and the re-check are separate milestones. The coding guide · See the community coder guide and the agent instructions.

3. Aggregator handler

It prepares a separate run and opens the aggregator's stages in order, each run in one or more legs whose checkpoints keep the earlier states. The aggregator composes the account and the checks record what was delivered; the interpretation stays with the authors. The aggregator guide · See the stage map below, the handler protocol and the agent instructions. Research agents start from the handler chats.
