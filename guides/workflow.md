# Run the study

Open three handler chats in order: the [collection handler](download.html), then the [coding handler](communities.html) and the [aggregator handler](aggregator.html). Give each its brief before asking it to obtain the working folders. Each guide has the prompt to paste, the checks and when to move on; below is what each handler does.

## 1. Collection handler

It builds each community's record from the public pixel record, the atlas and the Reddit archives, following the collection recipes; the census decisions come with the data. [The collection guide](download.html) · See the [data recipes](../sources/data-README.html) and the [agent instructions](../agents/download.html).

## 2. Coding handler

It codes each community with its community coder, and fleet coders above 500 items, and keeps each coder's conversation and files so the coder can be resumed. A local model (R6), the return and the re-check are separate milestones. [The coding guide](communities.html) · See the [community coder guide](../sources/coder-README.html) and the [agent instructions](../agents/communities.html).

## 3. Aggregator handler

It prepares a separate run and opens the aggregator's stages in order, each run in one or more legs whose checkpoints keep the earlier states. The aggregator composes the account and the checks record what was delivered; the interpretation stays with the authors. [The aggregator guide](aggregator.html) · See the stage map below, the [handler protocol](../sources/handler.html) and the [agent instructions](../agents/aggregator.html). Research agents start from the handler chats.
