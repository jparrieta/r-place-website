Start from raw data

Target length: under 650 words. Reading key for the Collection handler.

Start here

Open a Collection handler chat with shell and folder access. Use an empty study folder outside the instrument checkout. Give it the Collection brief and the prompt in the download guide. Keep the selected repository commit or supplied ZIP hash in its head.

Choose archived study inputs or a new collection. The instrument is available from the repository to accounts with access. The pristine package in the download guide contains an initial prepared aggregator run, not all raw stores or an aggregator conversation.

Required inputs and access

Provide the selected census and its judgments, the time window, output disk and authorized data locations. Read the source version's terms and store recipes before collecting. Existing public pixel and atlas routes, archived raw24, account material and member lists serve different tasks. Do not treat a missing store as optional unless the receiving contract permits it.

Some archive links remain unpublished. Original raw24 assembly cannot be reconstructed exactly from the documented recollection scripts. If reproduction needs those bytes, obtain the archived copy; do not quietly replace it with a new collection.

Read and check

  1. Collection handler.
  2. Data recipes, with resolved links, then the selected store instructions from that pinned version.
  3. Coding inputs and folder layout.
  4. Source and dependency versions.

Use the recipe's working directory and dependency list. Check storage before downloading, and use existing resume records after an interruption. The brief governs the head, diary and checks. A successful download alone does not establish coverage.

Deliver and continue

Leave HANDOFF-collection.md in the study folder. Record each required input's local path, original source, bytes, hash, time window, version, actual checks, gaps and ready or blocked status. Preserve the census separately from downloaded data.

Open the coding handler with this handoff. Coding starts only after its own input and launcher checks pass. The collection chat remains available for source questions.

Stop when

Stop the affected route if access is absent, required archived bytes are unavailable, a check fails, or the collection choice is unresolved. Name the missing store and the next action. Do not infer census decisions, run a historical yard, begin analysis or count an incomplete acquisition as ready.
