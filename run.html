Run the study

Start by opening a handler chat in Codex or Claude with access to a working folder. Give it the linked instructions before downloading data. The handler obtains and prepares the folders. You supervise decisions; handlers operate the work.

Three handlers, in order

  1. 1 Open the collection handler

    It obtains the Reddit archives, the pixel record, the atlas and the other required inputs, and leaves a checked handoff.

  2. 2 Open the coding handler

    It uses the existing handler to code the communities and save their community coders.

  3. 3 Open the aggregator handler

    It uses the existing handler to build and test the population model, stage by stage.

Each guide has a prompt to paste and explains the handoff to the next chat. Check platform requirements before starting.

Other ways in

  • Starting from coded communities

    Open the aggregator handler directly with checked coded inputs.

  • Forked run

    Resume a saved agent from its checkpoint and, instead of interviewing it, give it files and stage cards to start a new run; the original run stays as it was.

  • Checkpoint interviews

    Only auditing? Question the saved agents instead of running the study.
