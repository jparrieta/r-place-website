Run the study

Start by opening a handler chat in Codex or Claude with access to a working folder. Give it the linked instructions before downloading data. The handler obtains and prepares the folders.

Open the three chats in order:

  1. Collection handler: obtain raw24, pixels, atlas and the other required inputs.
  2. Coding handler: use the existing handler to code communities and save their leads.
  3. Aggregator handler: use the existing handler to build and test the global model.

Each guide has a prompt to paste and explains the handoff to the next chat. You supervise decisions; handlers operate the work. Check platform requirements before starting.

Already have checked coded communities? Start with the Aggregator handler and its input checklist.

Only auditing? Use checkpoint interviews.
