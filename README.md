# r/place website

Public reading website for r/place as a model organism for organization science.

This repository contains the built website, figures, reading copies, source recipes and the interview launcher. The research repository and checkpoint archives remain private. Three historical manual pages link to their private originals because those pages contain participant handles.

GitHub Pages serves this directory. `config.json` leaves `hosted_url` unset while online interviews are unavailable. When a tested interview server is ready, set that field to its HTTPS origin; the reading website can remain here.

No provider credentials, native checkpoint packages or private interview state belong in this repository. Reading copies and public comment IDs remain linkable to the source record.
