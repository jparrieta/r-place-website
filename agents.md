# Full reference for agents

This repository proposes r/place as a fruit fly for organization science: a shared event record and a revisable instrument for cumulative grounded theory. The [research object](guides/project.md), [common conditions](conditions.md), [whole event](event.md) and [shared data and tools](tools.md) explain the project.

Use these reading keys to find the authoritative instrument. They do not replace it.

For a human-readable explanation of who does what, see [Agents and their roles](guides/agent-roles.md).

Choose your starting point: [raw data](agents/download.md), [checked coded communities](agents/aggregator.md), or [checkpoint interviews](agents/interview.md). Each brief lists inputs, access requirements and stopping points.

For a new study, open the [Collection handler](agents/collection.md) first. Then use the existing [coding handler](agents/communities.md) and [aggregator handler](agents/aggregator.md), in separate chats. The collection brief is new; the other two retain their existing contracts. Human prompts and handoffs are in [Run the study](run.md).

1. Read the scope, inputs and stopping boundary for your task.
2. Read the linked contract and the full stage card, in the listed order.
3. Check the file hashes in the source manifest. If a version differs, report the difference before treating it as the same instrument.
4. Follow the handler's checks and handback rules. A website status is not permission to start, repair or resume research.

Every stage page offers its reading key as Markdown and its full card in HTML and Markdown. The source manifest identifies the version used to build this site. Checkpoint manifests separately identify historical agent state.

Use the [resolved source reading copies](reading/manifest.json) to follow links. Their wording matches the [exact canonical sources](sources/manifest.json); links resolve to other reading copies or a pinned repository commit. A missing dependency is marked, never supplied by guesswork.

An interview is an audit copy. Never update the original run, infer missing files from the latest workspace, or substitute a fresh agent when native restoration fails.

For an evidence audit, read the [TRACE reading guide](guides/audit-evidence.md) and [evidence register](evidence.json). Distinguish instructions from recorded actions and recorded actions from independent acceptance. The bounded example does not certify the whole study or add research requirements.
